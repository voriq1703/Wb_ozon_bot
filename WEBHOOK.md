# Как подключить Grok Bot

1. Подними маленький сервис (FastAPI / Flask / любой), который принимает POST на `/grok-webhook`.
2. В этом сервисе при получении заявки вызывай Менеджера карточек (через доступный тебе способ работы с Grok Bot).
3. Сервис должен вернуть HTTP 200, если заявка успешно передана в работу.
4. URL этого сервиса пропиши в `.env` в переменную `GROK_WEBHOOK_URL`.

Пример тела, которое присылает бот:

```json
{
  "request_id": 15,
  "user_id": 123456789,
  "username": "username",
  "data": { ... }
}
```
